# Glyphoxa — design decisions

Decisions are recorded as Architecture Decision Records under
[docs/adr/](docs/adr/), indexed in full in the
[documentation index](docs/README.md#architecture-decision-records). Later
changes to a decision are dated amendments inside the original ADR. Domain
language lives in [CONTEXT.md](CONTEXT.md); what the decisions add up to in the
tree today is [docs/architecture.md](docs/architecture.md).

Older code comments cite design-grilling question numbers (e.g. "Q13.4"). Each
question was resolved into one or more ADRs; Q13.4 (address detection and
multi-NPC turns) became [ADR-0024](docs/adr/0024-address-detection-deterministic-fuzzy-chain.md) and
[ADR-0025](docs/adr/0025-ensemble-turns-speculative-lead-reaction.md)).
